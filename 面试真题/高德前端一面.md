### js报错修改这块怎么做的？有没有遇到不好解决的bug，怎么处理的
一般会先通过监控系统定位错误，再结合 sourcemap、用户路径和接口日志复现。

常见上报方式：

- `window.onerror` 捕获 JS 运行错误
- `unhandledrejection` 捕获 Promise 未处理错误
- Vue 用 `Vue.config.errorHandler`
- 请求错误在 axios 拦截器里统一上报

处理流程：看影响范围、定位源码、复现问题、修复发版、观察错误量是否下降。

不好解决的 bug 一般是偶现问题，比如某些机型白屏。处理方式是补充更多日志、记录用户操作链路、加灰度验证，逐步缩小范围。

### 2.vue2和vue3区别 常考
主要区别：

- 响应式：Vue2 用 `Object.defineProperty`，Vue3 用 `Proxy`
- API 风格：Vue2 主要是 Options API，Vue3 支持 Composition API
- 性能：Vue3 编译优化更好，包体更小，渲染更快
- TypeScript：Vue3 对 TS 支持更好
- 多根节点：Vue3 组件支持 Fragment，多根节点
- 生命周期：Vue3 中 `beforeDestroy/destroyed` 改为 `beforeUnmount/unmounted`

简单总结：Vue3 性能更好、组合逻辑更方便、TS 支持更完善。
 
### 3.nextTick原理
Vue 更新 DOM 是异步的。数据变化后，Vue 会把组件更新放进队列，同一轮事件循环里的多次修改会合并执行。

`nextTick` 的作用是在 DOM 更新完成后执行回调。

底层优先使用微任务，比如 `Promise.then`，不支持时再降级到 `MutationObserver`、`setImmediate`、`setTimeout`。

使用场景：修改数据后，马上要获取最新 DOM。

### 4.组件封装思路？颗粒度考虑（经常问）
组件封装主要看复用性、维护性和职责边界。

- 基础组件：颗粒度细，比如 Button、Input、Modal
- 业务组件：颗粒度适中，比如用户卡片、任务列表
- 页面组件：负责数据请求和业务编排

封装时要明确 `props`、事件、插槽，避免组件内部写死业务逻辑。

颗粒度太细会增加维护成本，太粗又难复用。一般按“单一职责 + 是否多处复用”来拆。

### 5.事件循环
事件循环执行顺序：

1. 执行同步代码
2. 清空微任务队列，比如 `Promise.then`
3. 执行一个宏任务，比如 `setTimeout`
4. 再清空新产生的微任务

例子：

```js
console.log(1);
setTimeout(() => console.log(2));
Promise.resolve().then(() => console.log(3));
console.log(4);
```

输出：`1 4 3 2`。

### 6.事件委托
事件委托是把子元素的事件绑定到父元素上，利用事件冒泡统一处理。

优点：

- 减少事件绑定数量
- 动态新增的子元素也能响应事件
- 方便统一管理

```js
document.querySelector('ul').addEventListener('click', e => {
  if (e.target.tagName === 'LI') {
    console.log(e.target.textContent);
  }
});
```

### 7.promiseAll手写
```js
function promiseAll(list) {
  return new Promise((resolve, reject) => {
    const result = [];
    let count = 0;

    if (list.length === 0) {
      resolve([]);
      return;
    }

    list.forEach((item, index) => {
      Promise.resolve(item).then(res => {
        result[index] = res;
        count++;
        if (count === list.length) {
          resolve(result);
        }
      }).catch(reject);
    });
  });
}
```

特点：全部成功才成功；有一个失败就直接失败；结果顺序和传入顺序一致。

### 8.数组拍平手写 常考
```js
function flatten(arr) {
  const result = [];

  for (const item of arr) {
    if (Array.isArray(item)) {
      result.push(...flatten(item));
    } else {
      result.push(item);
    }
  }

  return result;
}

console.log(flatten([1, [2, [3, 4]]])); // [1, 2, 3, 4]
```

### 9.数组转树手写 常考
```js
function arrayToTree(list) {
  const map = {};
  const tree = [];

  list.forEach(item => {
    map[item.id] = { ...item, children: [] };
  });

  list.forEach(item => {
    const node = map[item.id];
    if (item.parentId == null) {
      tree.push(node);
    } else {
      map[item.parentId]?.children.push(node);
    }
  });

  return tree;
}
```

核心思路：先用 map 存 id 和节点，再根据 `parentId` 找父节点挂载。

### 10.react用过没
可以这样回答：

有了解和简单使用。React 核心是组件化和状态驱动视图，常用 `useState`、`useEffect`、`useMemo`、`useCallback`。

和 Vue 最大区别是：Vue 模板语法更多，响应式由框架自动追踪；React 更偏函数式，状态变化后通过重新执行组件函数生成新的 UI。
