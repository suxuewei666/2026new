.flex-container {
  display: flex;
  flex-wrap: wrap;
  align-content: stretch;
}

align-content属性详解

什么是align-content?

align-content属性定义了多行Flex容器中项目在交叉轴上的对齐方式。它不会影响单行的Flex容器。

适用条件

  • 仅适用于多行Flex容器（flex-wrap: wrap 或 wrap-reverse）
  • 容器必须有固定的高度
  • 项目总高度小于容器高度时，此属性才会生效

属性值说明

  • stretch：默认值，项目被拉伸以填满容器
  • flex-start：项目在容器顶部对齐
  • flex-end：项目在容器底部对齐
  • center：项目在容器垂直居中
  • space-between：项目均匀分布，第一行在顶部，最后一行在底部
  • space-around：项目均匀分布，每个项目周围有相等的空间
  • space-evenly：项目均匀分布，项目之间的间隔相等

与align-items的区别

align-items控制单行项目在交叉轴上的对齐方式，而align-content控制多行项目在交叉轴上的对齐方式。
