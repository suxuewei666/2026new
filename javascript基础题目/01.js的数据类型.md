## 1.js的数据类型

### 1.1 基本数据类型

Number String Boolean Undefined Null Symbol Bigint

### 1.2 引用数据类型

Object

### 1.3 判断数据类型

typeof 不能判断Object类型

instanceof 判断某个对象是否由某个构造函数创建（只能用于引用类型）。 只能判断Object类型，对基本类型无效

Object.prototype.toString.call() 这个方法会返回一个格式为 [object Type] 的字符串，其中 Type 表示值的类型。
常用封装Object.prototype.toString.call(value).slice(8, -1)

instanceof 通过在左侧对象的原型链上逐级查找右侧构造函数的 prototype 来判断归属；它可被 Symbol.hasInstance 重写，受原型链与跨 realm 环境影响，对原始值无效，适合自定义类实例判断，不适合跨窗口对象与基本类型。
